## 原件公开前的最小条件

1. 权利人确认文件版本、公开范围、再分发许可
2. 发布字节重新计算SHA-256；若转成Markdown/PDF，保留原文件哈希并另记转换件哈希
3. 同时保留条款编号与转换说明，避免转换过程静默改写义务
4. 单独审阅隐私信息、第三方资料和不宜公开内容
5. 明确哪一件是规范性原件、哪一件是导读或候选提案

在这些条件成立以前，本目录继续使用公开摘要与来源链接。OPP已有公开规范可从[原仓库固定版](https://github.com/xingxuling/OPP/blob/da65ab1d26c01c5e2939294e415b9fd07b7dbe5a/docs/SPECIFICATION.md)阅读，其内容不会被本目录重定义。
