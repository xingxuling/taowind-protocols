# P11 · 世界与数据上下文

英文登记名：World and Data Context  
类型：路线图能力域，不是已完成的独立协议发行版  
上游域状态：`partial`，来源注册表版本 `0.1.0-alpha.20`

## 要解决的问题
指明请求属于哪个世界/数据上下文，保持既有权威归属。

## 目前公开登记的有限实现
绑定worldId并禁止权威世界动作；当前只持世界引用。

## 仍缺什么
RNCS/RFE运行时适配、世界同步、数据生命周期和隐私执行尚缺。

## 所有权边界
- RNCS/RFE canonical world state
- TWNI world reference only
