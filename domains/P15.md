# P15 · 旧网互操作

英文登记名：Legacy Interoperability  
类型：路线图能力域，不是已完成的独立协议发行版  
上游域状态：`partial`，来源注册表版本 `0.1.0-alpha.20`

## 要解决的问题
在保留现有互联网协议职责的前提下形成受控兼容路径。

## 目前公开登记的有限实现
注册表记录固定OPP源的只读HTTP观察、JSON投影、根化回执和本地consumer验收绑定。

## 仍缺什么
DNS/TLS/浏览器/应用的一般兼容、通用HTTP迁移与独立第三方consumer尚缺；使用TCP不等于实现迁移协议。

## 所有权边界
- Existing Internet protocols retained
- TINP read-only HTTP transport adapter
- OPP CHP/RCP semantics retained by OPP
