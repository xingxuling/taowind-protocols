# P08 · 会话与连续性

英文登记名：Session and Continuity  
类型：路线图能力域，不是已完成的独立协议发行版  
上游域状态：`partial`，来源注册表版本 `0.1.0-alpha.20`

## 要解决的问题
故障、迁移或重启后保持主体、权限、证据的关联。

## 目前公开登记的有限实现
签名本地会话；Provider/来源迁移；Windows冷恢复；未决请求失败闭合，维护模式核对与整租约退役。

## 仍缺什么
跨设备重注册/转移、无外锚的整目录防回滚和副作用事务尚缺。

## 所有权边界
- TWNI network session profile
- RCL invariants
- RNCS domain session retained
